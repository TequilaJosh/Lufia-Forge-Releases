# Lufia Forge — Releases

Downloads for **Lufia Forge**, a ROM editor for *Lufia & The Fortress of Doom* (SNES, US).

## Install

1. Open [Releases](https://github.com/TequilaJosh/Lufia-Forge-Releases/releases) and pick the newest version.
2. Download **LufiaForge-win-Setup.exe** and run it (Windows 10/11, 64-bit).
   Prefer no installer? Download **LufiaForge-win-Portable.zip** and unzip it anywhere.
3. Open your own copy of the ROM. Lufia Forge never overwrites it; edits are saved as dated copies next to it.

Installed copies check this page on start and update themselves.
Beta builds (versions like `0.4.0-beta.2`) also receive newer betas; stable builds only receive stable releases.

No ROM is included. You need your own legally obtained copy of the game.

This repository holds only the release files. Report problems on the [Issues](https://github.com/TequilaJosh/Lufia-Forge-Releases/issues) page.
